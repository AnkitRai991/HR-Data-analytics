Project Overview & Purpose

The HR Data Analytics Dashboard enables organizations to analyze employee data and understand key workforce trends such as:

Employee attrition and retention
Workforce demographics
Attendance patterns
Employee performance insights
Department-wise distribution
Hiring vs. exit trends

This project is useful for HR teams, managers, and analysts to make data-driven decisions for improving employee satisfaction and organizational efficiency.

🧰 Tools & Technologies Used
📊 Microsoft Excel – Data cleaning and preprocessing
🔄 Power Query – Data transformation and ETL process
📈 Power BI – Interactive dashboards and visual analytics
📊 Key Features
Cleaned and structured raw HR datasets using Excel and Power Query
Built automated data transformation workflows (ETL process)
Developed interactive Power BI dashboards for HR insights
Tracked employee attrition and turnover trends
Analyzed attendance and performance metrics
Segmented workforce by department, age, and role
📈 Dashboard Insights
Attrition rate analysis (overall and department-wise)
Employee demographics breakdown
Attendance and absenteeism trends
Performance evaluation patterns
Workforce distribution across departments
Hiring vs. attrition comparison
🚀 Business Impact
Reduced manual HR reporting effort
Improved visibility into workforce trends
Helped identify reasons for employee attrition
Supported strategic HR decision-making
Enabled faster and more accurate reporting
